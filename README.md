# TEMPO-7 v0.8.3

TEMPO-7 是一个以“当前正在做什么”为核心的个人时间段式日程系统。它根据当天安排与设备时间自动显示 CURRENT、NEXT、SCHEDULE、倒计时和进度，并提供 TODAY、WEEK PLAN、SOUND、LOOK、完整备份与个人云同步等功能。

## 当前版本：v0.8.3

### TODAY DELAY

v0.8.3 新增 TODAY DELAY，可将**仅当天**的整套日程系统性向后推迟指定时长。

- 可分别输入小时和分钟，设置从数分钟到数小时的总推迟量。
- `APPLY DELAY` 设置当天当前的总推迟量；再次应用时以新数值替换旧数值，不累计叠加。
- `RESET DELAY` 只取消推迟；`RESET TODAY` 同时清除 TODAY 临时修改和推迟。
- 推迟只作用于 TODAY，不修改原模板，也不改变 WEEK PLAN。
- 所有时间段整体后移，任务长度和任务之间原有间隔保持不变。
- CURRENT、NEXT、SCHEDULE、倒计时、进度以及 ENTRY / EXIT 铃声均按照推迟后的实际时间运行。
- TODAY 编辑器继续显示未推迟的基准时间，推迟量独立管理，避免把临时偏移写回长期日程。
- 推迟后超出当天 `23:59` 的部分直接截去；若一个时间段整体落到当天范围之外，则当天不再显示该任务。
- TODAY DELAY 会随完整备份和个人云同步一起迁移到其他设备。

### 当前主要功能

- **CURRENT / NEXT / SCHEDULE**：根据真实设备时间自动判断当前任务、下一任务和当天后续安排。
- **FREE TIME**：日程空档自动显示为空闲时间，不拉伸相邻任务。
- **TODAY**：可只针对当天修改、跳过、新增任务，并可另存为模板或导出当天 JSON。
- **TODAY DELAY**：仅当天整体后移日程，而不修改长期模板。
- **WEEK PLAN**：按星期自动选择模板，也可将某天设为 OFF。
- **TYPE**：内置任务类型，并支持最多 6 个自定义 TYPE、标签与颜色。
- **TASK NOTE**：每个任务可保存最多 200 字符的单行备注，并显示在 CURRENT、NEXT 与 SCHEDULE。
- **SOUND**：每个 TYPE 可独立设置 ENTRY / EXIT 音源；PREVIEW 支持播放、暂停和继续。
- **START GATE**：进入应用时通过统一启动界面开始当天运行，品牌信息会缩放并移动到正式界面的顶栏位置。
- **LOOK**：可调整界面、文字、边框和不同状态的显示颜色。
- **FULL BACKUP**：可完整导出和恢复个人配置与铃声音频。
- **PERSONAL CLOUD SYNC**：可在多台设备之间同步日程、设置、TODAY 数据与铃声音频，并在发生冲突时由用户选择保留哪一侧数据。
- **PWA / OFFLINE**：可安装为独立应用，并在离线状态下继续使用已有本地日程与铃声。

## 系列版本

### 0.8 Series — Start Gate、Cloud Sync 与当天控制

0.8 系列重点扩展应用启动体验、跨设备使用能力和 TODAY 的当天控制能力。

- 加入全屏 START GATE，以 `PRESS ANYWHERE TO START YOUR DAY` 作为进入正式界面的统一入口，并同时完成音频启动所需的用户交互。
- START GATE 中的 TEMPO-7 品牌信息不再作为独立启动元素消失，而是作为同一组界面元素缩放、位移并归位到正式页面左上角。
- AUDIO 顶栏控件简化为固定 `AUDIO` 文案，通过颜色和 hover 状态显示启用 / 禁用状态。
- 加入 Personal Cloud Sync，使日程、设置、TODAY 数据、自定义 TYPE 和铃声音频可以在多设备之间迁移和保持一致。
- 云同步发生不同设备同时修改时，不静默覆盖，而是提供显式冲突选择。
- SOUND 的 PREVIEW 从单纯试听扩展为播放 / 暂停 / 继续控制。
- 修复 NOTE 输入过程中无法正常保留空格的问题。
- v0.8.3 加入 TODAY DELAY，使整个今日日程可以统一向后移动而不影响长期模板。

### 0.7 Series — 数据完整性、编辑流程与任务表达

0.7 系列重点完善日程数据的迁移能力、TODAY 工作流、性能，以及 TYPE / NOTE / SOUND 的表达能力。

- FULL BACKUP 扩展为完整备份，可包含模板、WEEK、TODAY、外观、设置、自定义类型及铃声音频。
- 英文与主要数字界面改用项目内字体，并进一步统一主倒计时和工业风信息显示。
- TODAY 增加独立 JSON 导出，以及“保存为模板”“保存并应用到 TODAY”“保存并应用到 WEEK PLAN”等不同操作路径。
- 对长期运行进行性能优化，减少不必要的 DOM 更新、存储读取和 SCHEDULE 动画资源占用。
- 支持最多 6 个自定义 TYPE，每种 TYPE 都可以设置独立颜色和 ENTRY / EXIT 铃声。
- 每个任务加入 NOTE，可在 CURRENT、NEXT 和 SCHEDULE 中显示，并对溢出内容进行横向滚动展示。
- 修复 AUDIO 状态显示和进度条等界面回归问题。

### 0.6 Series — LOOK 与正式运行模式

0.6 系列将早期测试界面进一步转向日常正式使用。

- 加入 LOOK 外观系统，可调整背景、顶栏、面板、边框、文字及不同任务状态的颜色。
- 支持不同状态切换效果。
- 移除开发阶段使用的模拟时间模式，正式运行完全依据设备本地时间。
- 调整主倒计时的尺寸、字距和响应式表现。

### 0.5 Series — WEEK PLAN

0.5 系列加入周计划机制。

- 可为星期一至星期日分别指定模板。
- 某一天可以设置为 OFF / NO SCHEDULE。
- WEEK PLAN 启用后会自动根据当天星期选择对应模板。
- TODAY 仍可在当日基础上独立覆盖，不修改原有周计划和模板。

### 0.4 Series — PWA

0.4 系列将 TEMPO-7 从普通网页扩展为可安装的独立应用。

- 加入 PWA manifest、应用图标和独立窗口体验。
- 支持基础离线运行。
- 页面资源可缓存，本地已有日程在断网时仍可使用。

### 0.3 Series — TODAY Override

0.3 系列建立 TODAY 单日覆盖机制。

- TODAY 可对当天安排进行临时修改，而不直接改动长期模板。
- 支持当天任务编辑、跳过和新增。
- 当日修改按日期保存，到下一天自动回到正常模板 / WEEK PLAN 逻辑。

### 0.2 Series — Bell System

0.2 系列加入任务声音提示能力。

- 支持任务进入与离开铃声。
- 支持导入本地 MP3 / WAV 音源和试听。
- 增加铃声触发记录，避免同一事件重复播放。
- 后续版本在此基础上逐步扩展为所有 TYPE 的独立 ENTRY / EXIT SOUND。

### 0.1 Series — Core Routine Control

0.1 系列建立 TEMPO-7 最基础的运行框架。

- 建立 CURRENT、NEXT、SCHEDULE 和大尺寸主倒计时。
- 以时间段而不是待办事项作为日程基本单位。
- 支持模板编辑与本地保存。
- 日程空档自动识别为 FREE TIME。
- 加入 SCHEDULE 自动巡航、hover 暂停、手动滚动后延时恢复，以及到底后返回顶部等行为。
- 奠定石墨黑、强调色、大色块与高对比信息显示的工业控制界面风格。
