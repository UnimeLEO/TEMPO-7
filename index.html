LOCAL DATA

备份与恢复

TEMPO-7 平时自动把数据保存在当前浏览器中。v0.7.1 的 FULL BACKUP 会把模板、WEEK PLAN、TODAY OVERRIDE、外观、铃声设置以及已导入的 MP3 / WAV 音频本体一起封装进单个 JSON 文件，便于换设备或换浏览器后一键恢复。由于音频以 Base64 写入 JSON，备份文件会比原始音频略大。

浏览器音频播放权限和当前运行会话属于设备 / 会话状态，不会迁移；恢复后仍需点击一次 ENABLE SOUND / START TODAY 以重新激活声音。
